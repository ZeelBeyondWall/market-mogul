ZScript Developer Guide

Write custom technical analysis indicators to gain an edge in the markets

Introduction

ZScript is a secure, sandboxed client-side JavaScript engine designed to calculate custom technical indicators for the MarketMogul chart engine. You write a script that processes historical candle records, and the compiler automatically runs and plots the result directly on the chart canvas.

API Schema

Your script must contain a valid JavaScript expression or function body that takes a candles array as input and returns a numeric array of the exact same length.

1. The Candle Data Structure

Each candle in the candles array is an object with the following properties:

{
  o: number,  // Open price
  h: number,  // High price
  l: number,  // Low price
  c: number,  // Close price
  v: number,  // Volume
  t: number   // Millisecond timestamp (Unix epoch)
}

2. Return Requirements

  • Standard Mode (Single Line): Return an array of numbers (e.g. using map()) of the exact same length as candles.
  • Advanced Mode (Multiple Plots): Return an object with a plots array property. This lets you draw multiple lines with distinct styles, widths, and colors.

3. Multiple Plots & Styles

To render multiple lines or customize line styles, return an object matching the following structure:

return {
  plots: [
    {
      name: "Base line",
      values: trailValues,
      color: "#00ff00", // Or Array of strings for dynamic per-candle colors
      width: 2,         // Thickness in pixels (default 1.5)
      style: "solid"    // "solid" | "dashed" | "dotted"
    },
    {
      name: "Upper band",
      values: upperBand,
      color: "#ff3366",
      style: "dashed"
    }
  ]
};

4. Custom settings & Inputs

You can define customization options that users can modify in a settings popup without editing the ZScript code. Declare these inputs as special comments at the top of your ZScript: 

// @input bool useInternal = true "Use In-Built Smart Trail?"
// @input int itPeriod = 20 "Trend Sensitivity"
// @input float itMult = 3.0 "Trend Multiplier"
// @input color trailColor = "#00f0ff" "Trail Color"

The compiler parses these lines and automatically injects them into your script's execution context. You can reference these variables directly by name (e.g. itPeriod, itMult) anywhere in your script.

⚠️ Important: Price Overlay Rule

ZScript custom indicators are drawn directly as an overlay on the main price chart. Ensure that your return values match the price range of the active asset. For example, returning a fixed value like 50 (e.g. for RSI) on a stock priced at $1000 will render a flat line at the bottom of the screen.

ZScript Examples

You can copy and paste these working examples directly into the ZScript editor:

Example 1: Median Price Overlay

Returns the average of the High and Low prices for every candle.

// Calculate (High + Low) / 2
return candles.map(c => (c.h + c.l) / 2);

Example 2: Simple Moving Average (10-period SMA)

Calculates the average close price of the last 10 candles.

// 10-Period Simple Moving Average
return candles.map((c, i) => {
  if (i < 9) return null; // Not enough candles yet
  
  let sum = 0;
  for (let j = 0; j < 10; j++) {
    sum += candles[i - 9 + j].c;
  }
  return sum / 10;
});

Example 3: High-Low Spread Midpoint

Displays a channel line representing the midpoint of the high/low spread relative to the close price.

// High-Low Range Midpoint
return candles.map(c => {
  const range = c.h - c.l;
  return c.c + (range * 0.1); // Close price offset by 10% of candle range
});

Editor & Diagnostics

When you click Compile & Save, the engine performs a secure sandbox execution using sample data. If there is a syntax error or runtime issue (e.g. referencing an undefined property), the error stack trace will be printed directly in the editor status bar, highlighting the offending line.
