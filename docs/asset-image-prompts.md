# Asset Logo Image Prompts — MarketVerseX (100 assets)

## Kaise use kare

1. Har prompt ke aage ye **STYLE PREFIX** lagao (copy-paste):

> Minimal flat vector game app icon, a single centered emblem inside a dark navy (#0B1020) rounded-square badge with a subtle thin neon rim glow, clean geometric shapes, max 3 colors on dark background, soft inner glow, NO text, NO letters, NO numbers, NO watermark, crisp edges, 1:1 square, 512x512 —

2. Uske baad asset ka subject line paste karo (neeche table se).
3. **File naming (important):** generate hone ke baad file ko exact asset ID se save karo — e.g. `NEXA.png`, `USDNOVA.png`. Ek folder me sab daal dena (e.g. `asset-logos/`).
4. Format: PNG, 512×512. Transparent bg ki zaroorat NAHI — dark badge hi design ka part hai.

**Sector accent colors (consistency ke liye):** Tech = electric cyan/blue · Banking = gold/amber · Energy = orange + green · Healthcare = teal + white · Consumer = coral/pink · Gaming = violet/magenta · Crypto large = gold + cyan coin · Crypto mid = cyan/teal coin · Meme = playful multicolor · Forex = dual-tone circular exchange arrows

## Integration notes (mere liye, baad me)

- Files land in `client/public/assets/<ID>.png` (exact asset ID, case-sensitive).
- `AssetList`, `Chart` header, `Ticker`, `MoversTab` currently render `<svg><use href="#'+icon+'"></use></svg>` from `SvgDefs` — swap to `<img src={'/assets/'+id+'.png'}>` with SVG fallback when the PNG is missing (onError → hide img, show svg).
- Forex pair circles double as a fallback pattern if some generations fail.
